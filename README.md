# Amazon Clone

A responsive **Amazon homepage clone** built using **HTML and CSS**. This project recreates the visual structure and layout of Amazon's homepage as a front-end practice project.

## 📌 Project Overview

This project is a front-end recreation of the Amazon website homepage, developed to practice and strengthen my skills in **HTML5 and CSS3**.

The website includes a navigation bar, search section, hero banner, product categories, promotional sections, and a multi-section footer. The layout is designed to provide a similar visual experience to the Amazon homepage while using my own implementation.

## ✨ Features

* Responsive Amazon-style navigation bar
* Amazon logo and location section
* Search bar with category selection
* Language selection with flag
* Sign-in, Returns & Orders, and Cart sections
* Secondary navigation panel
* Hero banner section
* Product category cards
* Multiple shopping categories
* Hover effects and transitions
* Responsive grid layout
* "Back to Top" section
* Multi-column footer
* Font Awesome icons
* Google Fonts integration

## 🛠️ Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, responsiveness, and animations
* **Font Awesome** — Icons
* **Google Fonts** — Typography

## 📱 Responsive Design

The project uses CSS Grid, Flexbox, flexible widths, and media queries to improve the layout across different screen sizes.

For example, the product section uses an adaptive grid:

```css
grid-template-columns: repeat(auto-fit, minmax(326px, 1fr));
```

This allows the product cards to adjust according to the available screen width.

## 🚀 How to Run

1. Clone this repository:

```bash

```

2. Open the project folder.

3. Make sure all HTML, CSS, and image files are in the correct locations.

4. Open `index.html` in your browser.

You can also use **Live Server** in Visual Studio Code for a better development experience.
